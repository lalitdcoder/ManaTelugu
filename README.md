# Mana Telugu

An iOS app for learning Telugu from English, designed for kids and beginners.

## Features

- **Alphabet Learning**: Learn Telugu letters with stroke order animations and audio
- **Vocabulary**: Explore words organized by themes
- **Practice**: Review learned content with spaced repetition
- **Games**: Interactive games to reinforce learning
- **Progress Tracking**: Track your learning streak and XP
- **Kid Mode**: Special UI mode for younger learners
